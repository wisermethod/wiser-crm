# Wiser CRM Design

1. Easy on the eyes for all-day work.
2. Calm and beautiful.
3. Wiser suggested, not shouted.

Upstream’s `DESIGN.md` is kept unedited and is superseded by this reference for Wiser CRM.

The front matter lists the resolved default properties after `src/client/styles.css`
and `src/client/wiser-theme.css` load. The first value applies at `:root`.
The second applies when the root also has the `.dark` class. The matching
native color scheme applies to browser-drawn controls.

## Colour

Near-white, cool-grey dividers and ink-grey text form Mist’s light palette.
Dark mode uses a charcoal canvas with lighter cards and a deeper sidebar.
Card paint also fills popovers, dialogs and navigation hover. Deep teal fills
primary actions in both modes, with a lighter fill on hover and a pale label.
The light fill supplies its own edge and link-style button text. Dark mode
uses a separate edge and reads link-style button text from the accent text.
Inline links use the foreground colour with an underline and underline offset.

The brand mark, active navigation icons and counts, the selected record row
and sticky name cell, checked options, command selection and native checked
checkboxes read the accent family. Navigation icons at rest use muted text.
The selected sticky name cell carries a full-colour accent edge and a quieter
divider. Deals board states use the full ring. The brand link draws its focus
outline inside the row. Keyboard focus uses a solid outline, stronger inset
edges on controls and an additional inner edge on primary actions. Forced
colours supply the system Highlight focus colour.

The grid's decorative rules are soft. The input colour draws stronger inset
edges on interactive controls, and boundaries on outlined buttons and empty
radios. Empty native checkboxes use a 13px minimum, card fill, a solid input
edge and 3px corners in both modes. Checked and indeterminate checkboxes keep
their native glyphs. Forced-colours mode uses native checkboxes. Select and
combobox chevrons use 75% opacity. Mist adjusts destructive hover, its label
and the neutral category swatch.

## Type

The body uses the system sans-serif stack at 1.5 line height. Page headings
and dialog titles specified as semibold use weight 560. The fixed record
grid uses 14px type and 1.45 line height, with tabular figures for
right-aligned columns. The phone column uses 13px tabular figures.

## Shape and motion

The compact radius scale is 4px, 8px, 12px, 16px and 24px. Wiser’s 2rem card
radius is omitted to preserve the shape of small controls and tiles in the
record grid. The default primary button and the closed contact note action use
the 999px pill radius. The note form’s submit action takes over when the form
opens.

Cards and widgets use faint edges. Raised and floating surfaces add a short,
subtle shadow. The dialog uses a tinted scrim with 2px backdrop blur, and the
panel and scrim animate for 140ms at a fixed scale. Reduced-motion mode disables
both animations.

## Install branding

A signed-in install can supply a display name. The navigation shows it with
a small Wiser CRM label beneath it. The browser title reads “Name · Wiser CRM.”
An accent overrides only the teal family, using fitted marks, tints, text,
focus and primary tones in both modes. An install with no brand values uses
the default palette above and the Wiser CRM name.

## Signed-in account

The sidebar footer shows the signed-in email in muted text and an underlined
sign-out link in the foreground colour. The collapsed sidebar keeps the
sign-out icon available. On narrow screens the account sits beneath the
scrolling navigation. The waiting page puts the same link beneath its message.

The view-only bar spans the top of the main content. It uses the info tint,
an info-coloured heading and foreground body text. A refused change adds
bold feedback beneath the standing message.
